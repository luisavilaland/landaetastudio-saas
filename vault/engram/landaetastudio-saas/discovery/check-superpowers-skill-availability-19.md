# Check superpowers skill availability

**What**: Verifiqué que no existe una skill/directorio llamado `superpowers` en `~/.config/opencode/skills/` ni en `~/.claude/skills/`; tampoco hay coincidencias en scripts/workflows/código o skills globales.
**Why**: Aclarar si `superpowers` sigue siendo una dependencia operativa antes de migrar docs.
**Where**: rutas globales de skills y repositorio `saas-ecommerce`.
**Learned**: `AGENTS.MD` sí contiene tres referencias a `docs/superpowers/specs/` y `docs/superpowers/plans/`, pero son paths documentales, no una skill instalada.
